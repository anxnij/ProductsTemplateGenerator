# README — Формирование расценки новинок

## Что делает программа

Скрипт формирует итоговый Excel-файл на основе:
- файла-источника с листом `TPR new`
- Excel-шаблона с листами `For check` и `Discounts`

Программа:
- находит в источнике строки новинок по цвету ячейки в колонке **F**
- копирует шаблон в новый файл с датой следующего месяца в названии
- заполняет листы **For check** и **Discounts** служебными данными
- формирует блоки строк для условий `Y602` и `Y603`
- подставляет номенклатуру
- удаляет строки с нулевыми значениями скидки
- применяет стили и заливку к итоговым строкам

Итоговый файл сохраняется в папку шаблона.

## Структура входных данных

### Файл-источник
Ожидается лист:
- `TPR new`

Используемые колонки на листе `TPR new`:
- **F** — код материала
- **H** — номенклатура
- **M** — базовый процент для `Y602`
- **Q:X** — значения для customer code, строка 3 содержит коды клиентов

### Файл-шаблон
Ожидаются листы:
- `For check`
- `Discounts`

Лист `Discounts` также используется как источник стиля для строк данных.

## Ключевые бизнес-правила

### 1. Определение новинок
Строка считается новинкой, если:
- в колонке **F** есть значение
- ячейка **F** имеет цвет `FF00FF99`

Это задаётся константой:

```python
TARGET_GREEN_RGB = "FF00FF99"
```

### 2. Список кодов клиентов
Используется фиксированный список `CODES`:

- `SC`, `R4`, `R2`, `SA`, `S1`
- `SB`, `R0`, `R1`, `S9`
- `15578177`, `15363754`, `15363764`

Для каждого найденного материала формируются:
- блок `Y602` — по всем кодам клиентов
- блок `Y603` — по всем кодам клиентов

Итого на один материал создаётся:

```text
len(CODES) * 2
```

строк.

### 3. Особая логика для Y603
В `get_y603_value()` есть особые правила замены кода клиента:

- `15578177 -> S1`
- `15363754 -> S1`
- `15363764 -> R0`

Это влияет только на то, из какой колонки брать значение процента из источника.

### 4. Тип условия
Для каждой строки заполняется:
- `Y602`
- `Y603`

### 5. Определение типа клиента
В колонку **B** итогового листа записывается:
- `Customer number`, если код клиента состоит только из цифр
- `Customer group`, если код не числовой

### 6. Номенклатура
Номенклатура ищется по словарю:
- ключ: код материала из колонки **F** источника
- значение: номенклатура из колонки **H** источника

### 7. Удаление нулевых строк
После заполнения листа `For check` удаляются строки, где значение в колонке **G**:
- пустое
- `0`
- не приводится к числу

## Как работает программа

### Шаг 1. Проверка входных файлов
Функция `validate_workbooks()` проверяет наличие нужных листов:
- в источнике — `TPR new`
- в шаблоне — `For check`, `Discounts`

### Шаг 2. Поиск строк новинок
Функция `collect_green_rows()` проходит по строкам начиная с 5-й и ищет строки, где:
- колонка F непустая
- цвет ячейки F совпадает с `TARGET_GREEN_RGB`

### Шаг 3. Формирование имени итогового файла
Имя строится функцией `build_output_path_from_template()` по шаблону:

```text
Темплейт новинки_TPR GT_<дата>.xlsx
```

Где `<дата>` — первый день следующего месяца.

### Шаг 4. Копирование шаблона
`create_template_copy()` копирует шаблон в новый файл.

### Шаг 5. Очистка старых строк
`clear_old_rows()` удаляет все строки, начиная с 9-й, на листе `For check`.

### Шаг 6. Заполнение шапки
`fill_static_part()` записывает служебные значения в обе вкладки:
- email
- текущую дату
- тип операции
- фиксированные значения в строке 6
- дату в `G6`

### Шаг 7. Заполнение блоков Y602/Y603
`write_block()` создаёт:
- сначала строки `Y602`
- затем строки `Y603`

Каждая строка формируется через `write_code_row()`.

### Шаг 8. Применение стиля
`apply_data_row_style()` копирует стиль строки 9 с листа `Discounts`.

Дополнительно `force_data_fill()` принудительно ставит:
- серую заливку `FFD9D9D9`
- выравнивание по центру

### Шаг 9. Подстановка номенклатуры формулой
`fill_nomenclature_formula()` проставляет в колонке **J** формулу `VLOOKUP` на внешний файл-источник.

Пример логики:

```excel
=VLOOKUP(E9, '[ИмяФайла]TPR new'!$F:$H, 3, 0)
```

### Шаг 10. Сохранение файла
Итоговый файл сохраняется и показывается пользователю через `messagebox`.

## Основные функции

### `next_month_first_day()`
Возвращает первый день следующего месяца.

### `normalize_percent(value)`
Нормализует процент:
- понимает строки с `%`
- заменяет запятую на точку
- если значение между `-1` и `1`, умножает на `100`
- возвращает абсолютное значение

### `normalize_code(code)`
Приводит customer code к нормализованному виду:
- trim
- upper
- удаление пробелов

### `build_customer_map(ws)`
Строит карту соответствия:
- код клиента -> колонка

Поддерживает составные коды, например `R2,SB`.

### `get_y603_value(ws_src, row_idx, code, customer_map)`
Возвращает значение скидки для Y603 по нужной колонке источника.

### `build_nomenclature_map(ws_src)`
Строит словарь:
- `F -> H`

### `write_code_row(...)`
Записывает одну строку в итоговый лист.

### `write_block(...)`
Записывает полный блок строк `Y602 + Y603` по одному материалу.

### `delete_zero_rows(ws)`
Удаляет строки с нулевым значением скидки.

### `generate(source_path, template_path, operation)`
Главная бизнес-функция формирования файла.

## UI

Приложение запускается через класс `App(tk.Tk)`.

Поля интерфейса:
- путь к файлу-источнику
- путь к файлу-шаблону
- тип операции

Кнопка:
- `Сформировать файл`

Типы операций задаются в константе:

```python
OPERATIONS = [
    "Discount creation",
    "Modification",
    "Deletion"
]
```

## Важные зависимости от структуры Excel

Код сильно завязан на конкретную структуру файлов.

### Лист `TPR new`
Используются:
- старт данных с 5-й строки
- строка 3 для customer code в диапазоне `Q:X`
- колонка F — материал
- колонка H — номенклатура
- колонка M — базовый процент

### Лист `For check`
Ожидается, что данные начинаются с 9-й строки.

### Лист `Discounts`
Используется как:
- рабочий лист для заполнения шапки
- источник визуального стиля строки 9

Если структура шаблона или источника изменится, код нужно пересматривать.
