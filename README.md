Desktop-приложение на Python для автоматического формирования Excel-темплейта TPR по новинкам. Реализовано чтение исходного файла, поиск строк новинок по цвету заливки, обработка customer-кодов, расчёт значений скидочных условий Y602/Y603, генерация блоков строк для каждого материала, удаление нулевых строк и заполнение итогового шаблона с сохранением форматирования через openpyxl. Также добавлен графический интерфейс на Tkinter для выбора файлов и типа операции, валидация входных данных и автоматическое создание итогового файла с датой действия.
В работе выполнено:
Работа с Excel-файлами через openpyxl.
Автоматическое формирование Excel-файла на основе готового шаблона.
Копирование шаблона и создание нового итогового файла без перезаписи исходника.
Чтение данных из исходного Excel-листа и проверка наличия нужных листов.
Поиск нужных строк по цвету заливки ячейки.
Обработка бизнес-логики для TPR-новинок и расчёта скидочных условий.
Нормализация данных: обработка процентов, кодов клиентов, пустых значений и числовых форматов.
Автоматическое заполнение строк по заданному списку customer-кодов.
Генерация блоков условий Y602 и Y603 для каждого найденного материала.
Автоматическое удаление строк с нулевыми значениями.
Заполнение статической части шаблона: даты, тип операции, организация, тип скидки и период действия.
Работа с Excel-формулами, включая автоматическую вставку VLOOKUP.
Сохранение и копирование форматирования из листа-образца: шрифт, границы, формат чисел, высота строк, выравнивание и заливка.
Настройка визуального оформления итогового Excel-файла.
Валидация входных файлов и обработка ошибок.
Создание динамического имени итогового файла на основе даты начала действия.
